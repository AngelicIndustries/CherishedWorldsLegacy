# Cherished Worlds Legacy

Favorite worlds and servers in Minecraft 1.7.10.

<img src="src/main/resources/assets/cherishedworlds/logo.png" width="200" alt="Cherished Worlds">

[GitHub releases](https://github.com/AngelicIndustries/CherishedWorldsLegacy/releases) · [Discord](https://discord.gg/xAWCqGrguG)

## Features

Forge 1.7.10 backport of Cherished Worlds. Implementation in progress.

## Dependencies

Client-side mod for Forge 10.13.4.1614. Requires UniMixins. Et Futurum Requiem is optional.

## Building

```sh
./gradlew build
```

Java 8-compatible output using the GTNH buildscript. Before the first tag, use `VERSION=1.0.0-dev ./gradlew build`.
